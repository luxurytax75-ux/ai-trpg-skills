# シナリオ仕様（非公開）「苗床の三時」

## ルール
- 能力値5種: 体力/敏捷/知力/精神/魅力。初期値すべて0、合計+3を配分（各-1〜+2、-1を作ればその分+1追加可）。
- 部活ボーナス（1つ選択、該当技能+2）: 陸上部=逃走 / 剣道部=格闘 / オカ研=知識 / 写真部=調査 / 生徒会=説得 / 帰宅部=隠密
- 判定: 2d6+能力値(+部活) ≥ 目標（易6/普8/難10）。修正合計は±4まで。1・1は致命的失敗（追加の不利益）。6・6は自動成功。
- 技能→能力値: 格闘・強行突破・耐久・登攀=体力 / 隠密・逃走・回避・鍵開け=敏捷 / 調査・知識・推理・応急手当=知力 / SAN判定・集中・抵抗=精神 / 説得・嘘・聞き込み=魅力
- HP = 12+体力×2（最低10）。0で死亡（BAD「苗床」）。
- SAN = 40+精神×5。0で発狂（BAD「狂気」）。
- 時間: 行動1回30分。見る・考える・短い会話0分。移動は下表。開始21:00、期限03:00。
- 戦闘: 攻撃=格闘2d6+体力≥8で命中（素手1d3/包丁1d6/バット1d6+1/火2d6）。敵の攻撃は回避2d6+敏捷≥7で回避。逃走2d6+敏捷≥8。
- 回復: 救急箱1回 HP+1d3（1行動、所持中2回まで）。安全な場所での休息1行動 HP+1（1回のみ）。SAN回復なし。

## リソース消費（毎回事前に代償を描写で提示）
- SAN: 久我のノート精読(SAN-1d6)→核の位置・弱点・真名「ヌルガ・アム」/ 井戸壁の文字凝視(SAN-2d6)→「呼び声」習得: 苗人1体を1行動停止(精神判定8)/ 真名を唱える(SAN-1d3)→母が1行動硬直
- HP: 旧校舎窓破り(強行突破7、失敗HP-1d3、23時以降は音で苗人1体が寄る)/ 井戸へ直接降下(登攀8、失敗HP-2d6)で核まで1行動短縮/ 苗人を突っ切る(回避判定なしで1d6受けて通過)

- 移動: 自宅↔ミオ宅 徒歩15分 / 自宅↔学校 徒歩30分・自転車15分 / 学校↔交番 徒歩15分・自転車10分→15分扱い / 自宅↔交番 徒歩30分。バス終了済み。タクシー配車30分待ち（PCは所持金2000円、片道足りる）。

## 確定裁定（過去プレイで決めた世界の事実）
- 灯油はマッチの火を近づけても着火しない。布などの芯に染みさせれば着火する。床の灯油溜まりは燃える芯（手ぬぐい・紙）を落とせば広がって燃える。
- 自宅: 玄関に懐中電灯と雨合羽、物入れにガムテープ。自室の持ち物はキャラの部活に応じて追加可（剣道部なら竹刀1d3+1と胴：被ダメ-1・敏捷系-1、着用5分）。
- 学校: 新校舎2F廊下に煙感知器（紙の小火で作動は2d6≥7（確率であり難易度ではない））と非常ベル、廊下に消火器。発報時は警備会社が30分後に到着。掲示板の紙は焚き付けにのみ使える。

- 旧校舎が燃えた場合の延焼: 着火10分後に廊下中央・1F全体に煙（屋内は5分ごと耐久6、失敗HP-1、口を覆えば+1）、20分後に理科室・2F、40分後に屋根崩落でハッチ上が瓦礫に埋まる（地下は空気が残るが脱出不可、重機は翌朝）。
