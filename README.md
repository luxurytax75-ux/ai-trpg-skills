# ai-trpg-skills

Claude にTRPG（クトゥルフ風ホラーなど）のゲームマスターをさせるためのスキル集です。

## trpg-gm-plus

Claude がプレイヤーに見せないシナリオを先に作り、それに沿って1人用セッションを進行します。判定・HP・SAN（正気度）・時間制限が物語を動かします。

### 特徴

- **固定シナリオ方式**: 真相・NPC・時刻ごとのイベント・結末の条件を開始前に決めます。その場しのぎの後付けで話を作りません。
- **2d6 の確率設計**: 目標値は 易6／普8／難10 が基準。修正の合計は ±4 まで。「難易度高め」でも成功率が数%しかない判定は出ません。
- **戦闘の標準ルール**: 組みつき・目くらまし・武器落とし・多対一の釣り合い・HP0の扱いを開始前に決めます。黒幕が早々に捕まっても、敵の次の手と終盤の山場が用意されています。
- **時間の管理**: 腰を据えた行動は30分、会話や戦闘の1手は1〜3分で時計が進みます。何もしなくても状況は進みます。
- **ダイスボタン**: PCの判定はプレイヤーがボタンを押して振ります。判定のたびに、返答の末尾にその判定専用のボタン（技能名・修正・目標値入り）が出るので、画面の上まで戻る必要はありません。出目はブラウザの暗号用乱数で決まり、Claude には変えられません。1回押すと無効になるので振り直しもできません。ボタンに「念の言葉」を添えると、描写に織り込まれます。
- **読み物リプレイ**: 頼むと、台詞と場面描写のある読み物として書き起こします。
- **シナリオの共有**: 遊んだシナリオを配布用ファイルに書き出せます。受け取った人は、スキルと一緒に自分の Claude に渡すだけで同じシナリオを遊べます。

## インストール

### claude.ai（Web／デスクトップ／モバイルの Claude アプリ）

1. [trpg-gm-plus.zip](https://github.com/luxurytax75-ux/ai-trpg-skills/releases/download/latest/trpg-gm-plus.zip) をダウンロードします。main の最新版から自動で作られる ZIP です。解凍は不要です。
2. Claude で **Customize > Skills** を開き、「+」> **Create skill** > **Upload a skill** から ZIP をアップロードします。

自分で ZIP を作る場合は、`trpg-gm-plus` フォルダごと圧縮し、ZIP の中身が `trpg-gm-plus/SKILL.md` になるようにしてください。詳しくは [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude) を参照してください。

### Claude Code

```sh
git clone https://github.com/luxurytax75-ux/ai-trpg-skills.git
mkdir -p ~/.claude/skills
cp -r ai-trpg-skills/trpg-gm-plus ~/.claude/skills/
```

## 遊び方

### 新しいシナリオで遊ぶ

ジャンル・主人公・難易度・描写の強さを添えて呼び出します。

```
/trpg-gm-plus 豪華客船で世界一周の船旅。主人公はキャラメイク次第。難易度高、グロ目。
```

1. Claude がシナリオを作り、公開ルールを提示します。
2. 名前・職業・能力値の配分を返すと、キャラシートが出て開始です。
3. 行動を自由に書いて進めます。判定が必要になるとダイスボタンで振ります。
4. 終わったら「ネタバレ教えて」「リプレイ書いて」「配布版にして」などと頼めます。

### 人から受け取ったシナリオで遊ぶ

1. 受け取ったシナリオファイル（`○○_scenario.md`）は**開かずに**、そのまま Claude に添付します。中身は真相も結末も全部書いてあるGM用の資料です。
2. 次のように頼みます。

```
/trpg-gm-plus このシナリオでGMして
```

Claude はシナリオの中身を見せずに、キャラ作成から始めます。真相・配置・NPCの能力値・時刻イベント・結末条件はシナリオどおりに固定され、Claude が臨機応変に足すのは、シナリオにない行動への最小限の裁定だけです。描写がきつすぎるときは「描写を控えめに」と頼めば、数値や展開は変えずに表現だけ和らげます。

## シナリオの共有

### ファイルの分け方

スキルはセッション中、2つのファイルを分けて使います。

| ファイル | 中身 | 共有 |
| --- | --- | --- |
| `scenario.md` | シナリオそのもの。真相、公開情報、配置、NPC、時刻イベント、結末条件、PC背景の絡め方テンプレート。プレイ中は書き換えません | 配布できる |
| `session_log.md` | そのプレイの記録。PC固有の設定、出目、裁定、GMのミスの訂正 | 自分用 |

PC名や出目はシナリオ側に入らないので、`scenario.md` がそのまま他の人にも使える形で残ります。

### 配布版を書き出す

遊び終わったら、こう頼みます。

```
このシナリオを配布版にして
```

Claude は次の手順で `○○_scenario.md` を作って渡します。

1. プレイ中に決めた裁定のうち、次回以降も使えるもの（`[裁定・汎用]`）をシナリオ本文に組み込む
2. プレイで見つかった欠け（NPCの能力値の未設定、弱点を突く手段の偏り、想定外の展開への備えなど）を直す
3. PC固有の設定は、どのPCにも使えるテンプレートの形にして反映する
4. 版を上げて変更点を書き、難易度と時間の検証をやり直す

できたファイルを相手に渡せば、相手はスキルと一緒に Claude へ添付するだけで同じシナリオを遊べます。

### シナリオファイルの冒頭

配布用ファイルは次の形で始まります。受け取ったときの目印にしてください。

```
# シナリオ名
- 形式: trpg-gm-plus シナリオ v2
- 版: 1.0（作成日）
- 想定: プレイ時間、難易度、描写の強さ
- 注意: これはGM専用ファイル。遊ぶ人は中身を読まずに、trpg-gm-plus スキルを入れた Claude に添付して「このシナリオでGMして」と頼む。
```

形式 v2 より前の、シナリオとプレイ記録が1つにまとまった古いファイル（`trpg_world.md` など）も読めます。その場合、記録部分は読み飛ばして使われます。

## 注意

- ダイスボタンは、Claude が画面内にウィジェットを表示できる環境でだけ出ます。出せない環境では、Claude が乱数で代わりに振ってそう断ります。
- ボタンを押したときにアプリが確認を出すことがあります。これはアプリ側の表示で、スキルからは消せません。
- 同じシナリオでも、Claude の描写や台詞、プレイヤーの選択によって展開は変わります。固定されるのは、シナリオに書かれた事実とルールです。
